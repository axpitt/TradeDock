## Scope-control rule

Every new feature must be classified:

### V1 Required

Necessary for the agreed initial product.

### V1 Optional

Useful but can wait until core functionality is stable.

### V2

Useful after real usage data is available.

### Future

Not currently planned.

Do not add new functionality simply because a UI library or AI coding
tool suggests it.
